# 品牌配置

每个代运营客户 / 产品一个文件夹，里面一份 `brand.md`，可以再放商品数据、参考图。开工第一步先确定是哪个品牌，读它的 `brand.md`；没有就按下面的模板新建（问用户要缺的信息，不要编）。

| 文件夹 | 品牌 |
| --- | --- |
| `nrt/` | Naturestaurant 餐饮包装（出海匠画布，抓马系列） |
| `easybuy-xmas/` | EZ Easybuy Choice 4.5ft 植绒预装灯圣诞树（Brigo / EI 画布） |
| `rotibox/` | Rotibox 蓝牙音乐毛线帽 灰色款（Brigo / EI 画布） |

## brand.md 模板

```markdown
# 品牌配置：<品牌名>（<文件夹名>）

## 一、基本信息
| 项 | 内容 |
| 品牌 / 主推款 / 市场与平台 / 画布（出海匠还是 Brigo·EI）/ 商品来源 / 模特（有没有专用模特库，没有就写怎么定人物）/ 产品参考图 / 样板 |

## 二、产品事实（来源、抓取日期；不确定的不写）
## 三、表达限制（手卡、客户口径；哪些话不能说）
## 四、品牌名、网址、CTA、当前活动
## 五、画面与制作偏好（用户定过的风格、模型、分辨率、要不要定妆图）
## 六、发布前检查（本品牌专属）
```

规则：
- 品牌专属的口径只写在这里，不写进 `SKILL.md` 和 `references/`。
- 新教训如果是通用的（提示词格式、画布坑、时长），写进 `references/`；只对这个品牌成立的，写进这里。
